# 0001. Record architecture decisions

**Status:** Accepted
**Date:** 2026-10-04

## Context

Decisions about this project's architecture get made in conversations, pull requests and chat threads, and the reasoning is lost once the people involved move on.

## Decision

We record significant decisions as Architecture Decision Records in `docs/adr/`, numbered sequentially, using [`template.md`](template.md).

## Consequences

New contributors can read why the project looks the way it does. Superseded decisions stay in place and link to the record that replaces them.

## Alternatives considered

A wiki, which drifts away from the code it describes.
